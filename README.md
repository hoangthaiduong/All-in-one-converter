# All-in-One Converter — GitHub Pages Full UI v4

Static browser-first file converter. This version refreshes the full interface while keeping the existing conversion engine unchanged.

- `favicon.svg` — favicon đồng bộ với logo của ứng dụng.

## Deploy to GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)**.
5. Save and open the generated Pages URL.

No Node.js, npm, Vite or server is required.
